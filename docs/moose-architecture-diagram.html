Module Details

schema.ts
  • AgentDefinitionInfo — id, name, prompt, model, tools, spawnable
  • AgentFolder — id, name, color, agents[]
  • AgentFolderConfig — activeFolder, folders[]
  • AgentInstanceState — idle | working | error | question | spawning
  • AgentInstanceInfo — id, position, state, session, parent
  • AgentMessageType — question | scope_request | answer | result
definition.ts
  • readConfig() — Read & validate moose-agents.json
  • writeConfig() — Write + publish Bus event
  • list/get/create/update/remove — Agent CRUD
  • listFolders/createFolder/... — Folder CRUD
  • setActiveFolder() — Switch active folder
  • seedDefaults() — First-run preset seeding
instance.ts
  • create/get/remove — SQLite CRUD via Drizzle
  • move() — Update x, y position
  • setState() — Transition + BusEvent
  • spawn() — Full validated spawn flow
  • findBySessionID() — Reverse lookup
  • pickUniqueName() — Random from 64-name library
layout.ts
  • LAYOUT — Constants (100px min, 160px spawn, 144° arc)
  • repelOverlaps() — 3-iteration force-directed push
  • redistributeSiblings() — Even arc distribution
  • Callback injection to avoid circular imports
spawn.ts
  • isSpawnAllowed() — Check spawnable.agents[]
  • checkSpawnLimit() — Numeric or auto (max 20)
  • calculateChildPosition() — Initial placement
  • isOrchestrator() — Has spawnable agents?
communication.ts
  • send() — Typed parent-child messages
  • Child → Parent: question, scope_request, result
  • Parent → Child: answer, result
  • escalate() — Route questions up hierarchy
events.ts
  • Spawned — New instance created
  • StateChanged — idle/working/error/question
  • Deleted — Instance removed
  • Moved — Position changed
  • Message — Inter-agent message
  • GCWarning — Approaching timeout
gc.ts
  • 30-second sweep interval
  • Top-level agents never deleted
  • idle_timeout: 0 → immortal
  • Cascade delete: children first
  • Orphan session cleanup (60s grace)
  • GCWarning 30s before deletion
agent.ts (Bridge)
  • translateMooseToAgent() — Moose → OpenCode
  • buildToolPerms() — Expand tool groups
  • buildOrchestratorPerms() — task/todo/plan
  • buildPlanPerms() — Plan mode: deny edits
  • buildThinkingOptions() — Budget/effort

Storage

moose-agents.json (File)
  • Location: ~/.config/opencode/moose-agents.json
  • Contains: Agent definitions + folder structure
  • Format: { activeFolder, folders[] }
  • Managed by: definition.ts
  • Seeded on first run by seedDefaults()
SQLite (Drizzle ORM)
  • Table: agent_instance
  • Contains: Runtime canvas instances
  • Fields: id, workspace, definition, session, parent, x, y, state
  • Managed by: instance.ts
  • Ephemeral: instances cleaned by GC
